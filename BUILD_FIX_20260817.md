# Build fix — 2026-08-17

La imagen base `mcr.microsoft.com/playwright/python:v1.57.0-noble` no incluye el módulo `ensurepip` necesario para `python -m venv`.
El `Dockerfile` instala `python3.12-venv` en la etapa `builder` antes de crear `/opt/satys-venv`.
No cambia la lógica SATyS, los datos productivos ni el runtime de Playwright.
